Seamless migration workflow

How to transition data from old hardware to a clean Windows 11 installation.

01

Execute the Backup

Select the folders, browser details, and registries on your source machine. Package them into a compressed `.migratekit` archive file locally.

02

Transfer the Package

Move the portable archive file to your new Windows 11 target machine using an external drive, network share, or cloud folder.

03

Run System Restore

Unlock the restore engine inside the target machine using your license key, select your archive file, and click Execute System Restore.
