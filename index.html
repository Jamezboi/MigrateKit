FAQ

Practical answers.

The details that matter before a migration.

Is my data uploaded anywhere?

The desktop migration engine is designed around local file operations. The archive is created on your machine and moved by you.

Do I need the license to create a backup?

No. Backups are the free portion of the application. The license unlocks the restore workflow.

What happens to files that are locked?

Locked files can be skipped and reported. Chrome should be closed during migration for the most reliable profile capture.

Where do I get the executable?

Use the Download button at the top of this page or the latest GitHub release.
